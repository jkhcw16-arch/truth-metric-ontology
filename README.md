# Truth Metric Ontology

Domain-neutral OWL 2 ontology for assertions, propositions, evidence, provenance, temporal relationships, truth assessments, and findings.

## Files

- `index.html`: GitHub Pages landing page
- `Truth_Metric_Ontology.owl`: RDF/XML ontology
- `Truth_Metric_Ontology_Technical_Specification_v1_1.docx`: technical specification
